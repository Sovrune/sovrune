# Contributing

Thank you for helping build an accountable operating system for AI-run companies.

1. Open an issue describing the problem and expected behavior.
2. Fork the repository and create a focused branch.
3. Add or update tests.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request explaining the business and security impact.

By contributing, you certify the Developer Certificate of Origin 1.1 (`git commit -s`). Never contribute real company data, credentials, private endpoints, or customer information.
